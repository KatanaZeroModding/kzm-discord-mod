# KZM Discord

Discord Rich Presence для Katana ZERO через KZM. В статусе место, текущий трек и портрет персонажа. Спидран идёт через часы Discord (`timestamps.start`): секунды в текст не пишутся, поэтому статус не обновляется каждый тик.

## Что видно

- **Details** — место: меню, выбор уровня, глава или короткая сцена. Концовки и скрытые комнаты без названия сюжета.
- **State** — трек. Пауза один раз подменяет строку и возвращает трек, когда игра продолжилась. Смерти за сессию дописываются только в момент смерти.
- **Часы** — время забега, если спидран идёт, иначе время в текущей главе. Пауза снимает часы один раз. Продолжение ставит их один раз от игрового таймера.
- **Маленькая картинка** — Зеро, Fifteen или Снег.

Тихие варианты одного трека (`song_edm` / `song_edm_far`, музыка соседа рядом и далеко) не считаются сменой.

## Настройка

1. Создайте приложение на <https://discord.com/developers/applications> и скопируйте **Application ID**.
2. В **Rich Presence → Art Assets** загрузите:
   - `assets/avatars/zero.png` под ключом `zero`
   - `assets/avatars/fifteen.png` под ключом `fifteen`
   - `assets/avatars/snow.png` под ключом `snow`
   `zero.png` же поставьте иконкой приложения. Пока ключей нет, статус уходит без портрета.
3. Сборка:

```bash
bash ./build.sh
kzm build
```

`kzm build` сам DLL не компилирует. Плагин 32-битный, как игра (`i686-pc-windows-msvc`).

4. После первого запуска поправьте `mods/kzm-discord/discord.toml` в папке игры:

```toml
application_id = "123456789012345678"
language = "auto"      # auto, ru, en
privacy = "chapter"    # chapter или vague
show_elapsed = true
```

`auto` берёт язык игры из тех же глобалов, что и KZM. `vague` прячет место, трек и имя персонажа.

Пустой `application_id` ничего не делает и игру не трогает. Если Discord закрыт, плагин пробует снова. Ошибки связи — в `mods/kzm-discord/rpc.log`. Неизвестные комнаты, персонажи и поля таймера — в `discover.log`.

## Персонаж

1. Первая строка `kz_character_choice.txt` в корне игры (Katana SNOW пишет туда `snow`).
2. Иначе поле персонажа у игрока, у объекта спидрана или в глобалах.
3. Иначе Зеро.

## Проверка сборки

```bash
cargo test
bash ./build.sh
kzm validate .
kzm plugin verify .
```

Игру перед выкладкой закройте. В Discord бегущий таймер забега не должен мигать. Смена комнаты внутри главы часы не сбрасывает. Рестарт забега, пауза и снятие паузы обновляют статус по одному разу.

Остальные идеи — в [docs/BACKLOG.md](docs/BACKLOG.md).
